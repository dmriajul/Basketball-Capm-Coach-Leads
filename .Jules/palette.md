# Palette's Journal - UX & Accessibility Learnings

## 2026-07-08 - Table Cell HTML Formatting Constraints in GitHub Markdown
**Learning:** HTML `<abbr>` tags or markdown links (`[text](url)`) wrapped inside code backticks in GitHub Markdown tables format as raw code blocks and completely disable interactive features (hover tooltips and clickable links).
**Action:** Always place `<abbr>` tags and markdown links directly as unformatted inline Markdown/HTML elements within table cells.
