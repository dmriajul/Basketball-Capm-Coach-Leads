## 2026-07-08 - Accessible README Data Tables and Shortcut Hints

**Learning:** When presenting directory data in documentation-only repositories, replacing external link reliance with structured, accessible HTML/Markdown tables (using `<abbr>` for team abbreviations, direct `mailto:`/`tel:` protocol links, and `<kbd>` elements for keyboard search shortcuts) significantly enhances clarity, accessibility, and user navigation efficiency.
**Action:** Always structure tabular leads data with semantic `<abbr>` tooltips and direct action links (`mailto:`, `tel:`), while using GitHub-native admonitions with `<kbd>` hints for quick interaction guidance.
