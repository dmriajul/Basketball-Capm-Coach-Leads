## 2026-07-08 - Accessible Acronyms and Inlined Contact UX
**Learning:** In documentation-only projects where the README acts as the primary user interface, wrapping acronyms in `<abbr>` elements with descriptive title attributes and providing direct `mailto:` / `tel:` links significantly improves accessibility for screen reader users while dramatically reducing Time-to-Action for contact outreach.
**Action:** Always structure documentation preview tables with semantic HTML tags (`<abbr>`) and separated `<kbd>` tags for keyboard shortcuts without enclosing interactive elements in backticks.
