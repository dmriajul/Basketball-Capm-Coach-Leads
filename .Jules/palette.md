## 2026-07-08 - Accessible Link Protocols and Abbreviations in README Tables
**Learning:** Adding semantic HTML elements like `<abbr>` for abbreviations and clean `<kbd>` styling for keyboard shortcut hints within a table significantly enhances reader accessibility. However, wrapping interactive elements such as markdown links or `<abbr>` inside raw markdown table cells with backticks disables tooltips and hyperlink triggers under GitHub's markdown renderer. Furthermore, link labels should not include protocol prefixes like `mailto:` or `tel:` to maintain a clean, readable visual design.
**Action:** Always inline structural tables with raw `<abbr>` tags and clean labels for `mailto:` and `tel:` links. Ensure each keyboard shortcut uses separate `<kbd>` tags. Never wrap interactive links or abbreviations in table cells with backticks.
