## 2026-07-08 - Accessible Table Markup and Keyboard Hints
**Learning:** Adding `<abbr>` tags with descriptive `title` attributes for team acronyms in markdown tables gives screen reader users full context without cluttering the visible interface, while separate `<kbd>` tags improve visual clarity for key shortcuts.
**Action:** Always wrap team/organization abbreviations with `<abbr>` and format keyboard shortcuts using individual `<kbd>` tags in documentation tables.
