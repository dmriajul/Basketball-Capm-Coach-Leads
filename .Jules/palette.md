## 2026-07-08 - Semantic Markdown Enhancements for Plain Document Repositories
**Learning:** In documentation-only repositories, adding inline semantic `<abbr>` tooltips and direct action links (`mailto:`, `tel:`) combined with keyboard navigation hints (<kbd>Cmd/Ctrl+F</kbd>) significantly enhances accessibility and UX without modifying code logic or design tokens.
**Action:** When working on markdown-only repositories, structure lead tables with semantic tooltips and direct contact links for optimal screen reader accessibility and rapid time-to-action.
