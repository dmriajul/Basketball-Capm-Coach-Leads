# Palette's Journal - Basketball Camp Coach Leads

## 2026-07-08 - Semantic Micro-UX and Accessible Links in Leads Tables
**Learning:** Adding semantic HTML elements like `<abbr>` for team codes, direct protocol links (`mailto:`, `tel:`), and keyboard shortcut hints (`<kbd>`) inside documentation tables significantly improves accessibility and speed of interaction for users on desktop and mobile.
**Action:** Always provide full expansion via `title` in `<abbr>` and use separate `<kbd>` tags for modifier keys when documenting search shortcuts.
