## 2026-07-08 - Accessible Inlined Tables for Documentation Repositories

**Learning:** In documentation-only repositories, presenting complex or tabular roster data inlined with semantic `<abbr>` tags for team abbreviations and actionable `mailto:`/`tel:` protocols drastically improves user accessibility and scannability without relying on external files or code backticks inside cells.

**Action:** When structuring contact lists or rosters in Markdown, always use semantic `<abbr>` elements for acronyms and direct mailto/tel protocols, and include clear keyboard shortcut cues (`<kbd>`) inside alert callouts to enhance navigation efficiency.
