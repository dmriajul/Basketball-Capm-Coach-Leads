## 2026-07-08 - Accessible Acronyms and Inlined Leads UI
**Learning:** In documentation-centric interfaces, adding semantic `<abbr>` tags for team/league acronyms and direct `mailto:`/`tel:` action links significantly enhances screen reader context and reduces interaction friction without relying on external UI frameworks.
**Action:** Use semantic HTML tags (`<abbr>`, `<kbd>`) and explicit link titles in Markdown tables to improve keyboard and screen reader accessibility.
