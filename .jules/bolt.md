## 2026-05-31 - README as a High-Performance UI
**Learning:** In documentation-only repositories, the README.md is the application. Time-to-Content (TTC) and Time-to-Action (TTA) are the primary metrics. Linking to a Google Sheets `pubhtml` version (~9KB) instead of the full editor (~300KB+) reduces the data payload by ~97% and drastically improves TTA for mobile users.
**Action:** Implement "Fast View" links and inlined data previews to minimize user latency.
