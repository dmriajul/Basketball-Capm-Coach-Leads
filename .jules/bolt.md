## 2026-04-29 - Time-to-Content (TTC) Strategy
**Learning:** In documentation-only repositories, the README.md is the primary UI. Performance is measured by Time-to-Content (TTC) and Time-to-Action (TTA).
**Action:** Use zero-latency data previews and optimized external links to reduce initial user friction.

## 2026-05-04 - Payload Optimization via PubHTML
**Learning:** Providing a direct 'Fast View' link to the Google Sheets 'pubhtml' export (~9KB) reduces the initial data access payload by ~97% compared to the full spreadsheet editor UI (~300KB+).
**Action:** Always provide a 'Fast View' pubhtml link for large datasets hosted on Google Sheets.
