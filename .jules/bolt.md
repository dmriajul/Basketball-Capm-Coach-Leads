## 2025-05-14 - Optimizing Time-to-Content via Published Web Views
**Learning:** Loading a full Google Sheets editor for simple data viewing incurs a ~320KB payload, whereas the 'pubhtml' view is only ~9KB. Inline README previews provide zero-load evaluation.
**Action:** Prioritize published web views and direct CSV/PDF exports for documentation-centric repositories to minimize user wait time.
