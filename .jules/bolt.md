## 2026-05-26 - Documentation as UI for TTC/TTA Optimization
**Learning:** In documentation-centric repositories, the README.md acts as the primary User Interface. Standard performance metrics like Time-to-Content (TTC) and Time-to-Action (TTA) apply here. Providing a 'Fast View' link to a `pubhtml` export (~9KB) instead of the full spreadsheet editor (~300KB+) reduces the initial payload by ~97%.
**Action:** Always prioritize inlined previews and lightweight 'Fast View' links in documentation-only repositories to improve the speed of information delivery.
