## 2026-06-24 - Performance Metrics in Doc-only Repos
**Learning:** In repositories containing only documentation (README.md), traditional code optimizations (memoization, indexing) are impossible. "Performance" in this context refers to Time-to-Content (TTC) and Time-to-Action (TTA).
**Action:** Define README-based optimizations as structural improvements that reduce the user's journey to data. Ensure .jules/bolt.md is populated to provide context for this strategy.
