## 2025-05-22 - Performance Metrics for Documentation-only Repositories
**Learning:** In repositories where the README serves as the primary UI, performance is measured by Time-to-Content (TTC) and Time-to-Action (TTA). Inlining critical data eliminates network latency and reduces user friction.
**Action:** Use inlined tables, semantic HTML tags, and direct action links (mailto:, tel:) to optimize data access in documentation-heavy projects.
