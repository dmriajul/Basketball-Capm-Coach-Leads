## 2026-03-15 - [Bypassing Heavy Spreadsheet Interfaces]
**Learning:** For documentation-centric repositories, 'Time-to-Content' is a primary performance metric. Bypassing the full Google Sheets editor (~320KB) in favor of inline previews (0KB) and lightweight HTML views (~9KB) significantly improves UX for read-only users.
**Action:** Prioritize 'Fast View' options (pubhtml, CSV, PDF) and inline data samples in READMEs when external data sources are used.

## 2026-03-15 - [Data-to-Action Efficiency]
**Learning:** Providing actionable links (mailto:, tel:, direct downloads) within the README reduces 'Time-to-Action' and prevents context switching to external tools for basic tasks.
**Action:** Clean and localize data to provide immediate value through direct downloads and formatted contact links.
