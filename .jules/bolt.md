## 2026-06-09 - Performance Strategy for Documentation-as-UI
**Learning:** In documentation-only repositories, the README.md acts as the primary User Interface. Standard performance metrics like bundle size are irrelevant; instead, we prioritize Time-to-Content (TTC) and Time-to-Action (TTA). Replacing heavy spreadsheet editor links with lightweight 'pubhtml' exports reduces payload by ~97% and improves scannability.
**Action:** Implement 'Fast View' pubhtml links and inline scannable tables with semantic action links (mailto/tel) to minimize user friction.
