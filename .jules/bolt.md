## 2026-06-06 - Optimized README for TTC and TTA
**Learning:** In documentation-as-UI repositories, the README.md is the primary interface. Using the Google Sheets `pubhtml` export reduces the initial data payload by ~97% (from ~300KB+ to ~9KB) compared to the full editor. Inlining the top leads with emoji-prefixed `mailto:` and `tel:` links further reduces Time-to-Action (TTA).
**Action:** Prioritize `pubhtml` links and inlined scannable previews for any data-heavy documentation project.
