## 2026-05-22 - [TTC/TTA Focus in Doc-only Repos]
**Learning:** In repositories where the baseline consists only of documentation, introducing functional scripts (e.g., Python cleaning scripts) is perceived as creating a new project or premature optimization. Performance efforts should focus exclusively on Time-to-Content (TTC) and Time-to-Action (TTA) via README UI enhancements.
**Action:** Prioritize README structure, fast-path links (pubhtml), and inlined previews over functional code in documentation-centric missions.
