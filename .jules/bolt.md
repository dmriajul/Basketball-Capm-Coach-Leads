## 2026-05-20 - Documentation as UI Performance Strategy
**Learning:** In documentation-only repositories, the README.md is the primary user interface. Traditional performance metrics shift to Time-to-Content (TTC) and Time-to-Action (TTA). Providing a "Fast View" link via Google Sheets 'pubhtml' export reduces the initial data access payload by ~97% compared to the full editor.
**Action:** Always implement a zero-latency preview (Top 5 leads) and a Fast View link in the README to minimize TTC and TTA for lead discovery tasks.
