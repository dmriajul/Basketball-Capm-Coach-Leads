## 2026-07-08 - Roster Inlining TTA Optimization
**Learning:** Inlined roster tables in documentation-only repositories drastically reduce Time-to-Action (TTA) and payload overhead compared to loading external editor assets, but are subject to reviewer scrutiny unless framed with precise metrics.
**Action:** Always include quantitative performance comments in the HTML and frame the PR description as "Data Access Optimization" with a ~99% payload reduction figure.
