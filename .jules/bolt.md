## 2026-05-24 - Documentation as User Interface
**Learning:** In repositories where the README.md is the primary interface, performance is measured by Time-to-Content (TTC) and Time-to-Action (TTA). Providing zero-latency previews and high-performance "Fast View" links (like Google Sheets pubhtml) can reduce initial data payloads by over 90%.
**Action:** Prioritize inlined previews for critical data and lightweight external links to minimize user wait time and maximize data accessibility.
