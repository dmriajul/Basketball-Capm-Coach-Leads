## 2026-03-15 - Time-to-Content Optimization for Docs

**Learning:** In documentation-centric repositories, performance is measured by 'Time-to-Content' and 'Time-to-Action'. Bypassing heavy external interfaces (like Google Sheets' 320KB editor) in favor of inline previews and lightweight web views (9KB pubhtml) significantly reduces user latency.

**Action:** Implement 'Quick Preview' tables for top-tier data and use direct CSV/pubhtml links to minimize the path from discovery to utility.
