## 2026-07-08 - Improving Data Access in Documentation-only Repositories
**Learning:** In repositories containing only documentation, the primary UX/performance metric is the Time-to-Action (TTA). Enhancing the README to present critical information inlined (like standard team abbreviations, formatted emails/phones, and search tips) significantly improves scannability and keyboard navigation. Using precise semantic HTML tags (<abbr> for team codes, <kbd> for shortcut keys) allows screen readers and power users to navigate the leads table with ease.
**Action:** Always structure reference tables with standard accessibility aids (like explicit mailto/tel protocols, descriptive abbreviations, and helpful keyboard shortcuts) and format labels with clean, human-readable strings rather than exposed protocols. Ensure simulation metadata is accurate to the confirmed date.
