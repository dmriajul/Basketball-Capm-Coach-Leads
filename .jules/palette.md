## 2025-05-15 - Multi-tag Keyboard Shortcuts
**Learning:** For optimal accessibility and visual clarity, keyboard shortcuts should use individual `<kbd>` tags for each key (e.g., `<kbd>Cmd</kbd> + <kbd>F</kbd>`) rather than a single tag. This increases the total tag count in structural verification scripts.
**Action:** Always wrap modifier keys and character keys in separate `<kbd>` tags and account for this in automated README verification scripts.
