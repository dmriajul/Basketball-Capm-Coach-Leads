## 2026-03-25 - Accessibility with Abbreviation Tags
**Learning:** Using `<abbr>` tags for industry-specific acronyms (e.g., NBA, NCAA) in documentation significantly improves accessibility for screen reader users and provides helpful hover context for users unfamiliar with the terminology, without adding visual noise to the interface.
**Action:** Identify acronyms in user-facing text and wrap them in `<abbr>` tags with descriptive `title` attributes to enhance both accessibility and clarity.
