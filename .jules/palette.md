## 2026-04-21 - [README-as-UI Pattern]
**Learning:** In documentation-centric repositories, the README acts as the primary interface. Using thematic emojis, clear "Quick Access" sections with performance-oriented descriptions (e.g., "Zero-latency"), and accessible preview tables significantly reduces Time-to-Content.
**Action:** Always structure README updates to include a fast-access section and use semantic tags like `<abbr>` for domain-specific acronyms and `<kbd>` for interface hints.
