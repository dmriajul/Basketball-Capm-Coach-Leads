# 🎨 Palette's UX Journal

## 2026-03-20 - [Accessibility: Acronyms in Documentation]
**Learning:** Using `<abbr>` tags with `title` attributes for industry-specific acronyms (like NBA, NCAA) in README documentation improves screen reader context and provides helpful tooltips for users without cluttering the main text.
**Action:** Always wrap technical or organization acronyms in `<abbr>` tags when they first appear or in key data sections.

## 2026-03-20 - [UX: Cross-Platform Search Instructions]
**Learning:** When providing keyboard shortcut tips for searching (like Ctrl+F), including the Mac equivalent (Cmd+F) ensures the documentation is inclusive of all users and reduces "Time-to-Search" for Apple users.
**Action:** Use the format `Ctrl + F (or Cmd + F on Mac)` for search instructions.
