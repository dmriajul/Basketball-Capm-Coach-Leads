## 2026-06-29 - Semantic Table Enhancements for Documentation-Only Repos
**Learning:** In repositories where the README serves as the primary UI, using semantic HTML tags like `<abbr>` for tooltips and direct action links (`mailto:`, `tel:`) significantly improves accessibility and user scannability without adding external dependencies.
**Action:** Prioritize scannable tables with semantic tags and direct action links when enhancing documentation-heavy interfaces.
