## 2026-05-21 - Documentation as a User Interface
**Learning:** In documentation-only repositories, the README.md is the primary UI. Enhancing it with semantic HTML (<abbr>, <kbd>), action-oriented links (mailto:, tel:), and visual cues (emojis, badges) significantly reduces Time-to-Action (TTA).
**Action:** Prioritize scannability and direct accessibility features in README files to improve the developer/user experience.
