## 2026-07-08 - Basketball Camp Leads UX Optimization
**Learning:** In documentation-only repositories, the README.md acts as the primary user interface. To improve Time-to-Action (TTA), complex external resources (like raw spreadsheets) can be inlined as a highly readable, accessible Markdown table using semantic HTML element combinations. Adding `<abbr>` for context, formatted direct email/phone links without protocols in the label text, and standard keyboard shortcut formatting (<kbd>) in native GitHub tip admonitions yields an excellent, zero-latency search experience.
**Action:** Always verify proper element counts (e.g. `<abbr>`, `mailto:`, `tel:`, `<kbd>`) programmatically via custom diagnostic scripts placed outside of the workspace, and ensure all local data exports are deleted before final submit.
