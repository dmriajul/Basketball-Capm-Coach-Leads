## 2026-07-05 - Semantic Accessibility in Documentation-Only Repositories
**Learning:** In repositories where the README acts as the primary user interface, semantic HTML tags like `<abbr>` for tooltips and `<kbd>` for keyboard shortcuts significantly improve accessibility and scannability without requiring external dependencies or complex UI frameworks.
**Action:** Prioritize the use of standard HTML5 semantic elements within Markdown to enhance the UX of documentation-centric projects.
