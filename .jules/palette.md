## 2026-05-14 - Accessible Documentation as UI
**Learning:** In documentation-centric repositories where the README.md acts as the primary User Interface (UI), semantic HTML tags like `<abbr>` (for acronym expansions) and `<kbd>` (for keyboard shortcuts) significantly improve accessibility and 'Time-to-Action' for users navigating datasets.
**Action:** Always incorporate `<abbr>` for industry-specific acronyms and `<kbd>` for interface hints when the README is the primary entry point.
