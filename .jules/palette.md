## 2025-05-15 - [README Scannability with Quick Preview]
**Learning:** For documentation-centric repositories, providing an inline "Quick Preview" table with icons and actionable links (mailto:, tel:) significantly reduces Time-to-Content and improves UX by allowing users to evaluate data without leaving the page.
**Action:** Use a consistent 4-column structure (Camp, Team, Coach, Contact) for mobile responsiveness and include descriptive 'title' attributes on all external links for better accessibility.
