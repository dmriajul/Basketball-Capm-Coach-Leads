## 2026-06-16 - Documentation as a User Interface
**Learning:** In repositories consisting solely of documentation, the README.md is the primary User Interface. Accessibility and UX can be significantly improved by using semantic HTML tags like `<abbr>` for abbreviations and `<kbd>` for keyboard shortcuts, alongside protocol-specific links (`mailto:`, `tel:`) to reduce Time-to-Action (TTA).
**Action:** Prioritize scannable tables with direct action links and semantic enhancements in documentation-heavy or documentation-only projects.
