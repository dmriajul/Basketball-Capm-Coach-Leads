# Palette's Journal - Critical UX/Accessibility Learnings

## 2026-03-25 - [README-Centric UX for Data Repositories]
**Learning:** In repositories that are primarily data-driven (CSV/Python) without a frontend, UX enhancements should focus on the `README.md` to bridge the gap between raw data and usability. Accessibility patterns like `<abbr>` for domain-specific acronyms and `<kbd>` for shortcuts significantly improve scannability and screen reader context for non-technical users.
**Action:** Always check `README.md` for undocumented acronyms and provide tooltips/labels using semantic HTML to improve the "Time-to-Content" and "Time-to-Action" for data consumers.
