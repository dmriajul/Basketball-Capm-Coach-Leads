## 2026-07-08 - Accessible Scannable Tables in Documentation
**Learning:** In documentation-heavy repositories where the README serves as the primary UI, using semantic HTML tags like <abbr> for tooltips and <kbd> for keyboard shortcuts significantly improves accessibility and user scannability without adding external dependencies.
**Action:** Always prioritize semantic HTML (abbr, kbd, mailto, tel) when presenting data in READMEs to enhance 'Time-to-Action' and ensure accessibility.
