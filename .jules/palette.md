## 2026-06-26 - Semantic HTML and Actionable Links in Documentation

**Learning:** In documentation-only repositories where the README is the primary UI, micro-UX improvements like semantic `<abbr>` tags and protocol-specific links (`mailto:`, `tel:`) significantly enhance accessibility and Time-to-Action (TTA).

**Action:** Use `<abbr>` for industry-specific abbreviations and ensure all contact info is wrapped in actionable protocols to make the documentation feel like a functional interface.
