## 2026-05-26 - Documentation as a User Interface (UI)

**Learning:** In documentation-centric repositories, the README.md is the primary UI. Reducing 'Time-to-Action' (TTA) by providing keyboard hints (<kbd>), semantic expansions (<abbr>), and emoji-prefixed deep links (mailto, tel) significantly improves accessibility and utility for users navigating small datasets.

**Action:** When working on doc-only repos, prioritize structured tables with semantic HTML and quick-access navigation aids over plain lists.
