## 2026-07-08 - Improving Data Access in Documentation-only Repositories
**Learning:** In documentation-only projects, semantic HTML such as `<abbr>` tooltips and `<kbd>` keys significantly enhance keyboard scannability and context without bloated JS bundles. Avoid protocol prefixes like `tel:` in labels for a cleaner screen reader experience.
**Action:** Always inline accessibility-focused structures directly into markdown while keeping them readable, semantic, and highly scannable using standard HTML tags.
