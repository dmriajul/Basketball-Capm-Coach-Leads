## 2026-06-25 - Semantic HTML in Documentation
**Learning:** In repositories where the README.md serves as the primary user interface, incorporating semantic HTML tags like `<abbr>` for tooltips and `<kbd>` for keyboard shortcut hints significantly improves scannability and accessibility without adding external dependencies.
**Action:** Use semantic HTML tags and GitHub-native admonitions to enhance the "Time-to-Action" for data-heavy documentation files.
