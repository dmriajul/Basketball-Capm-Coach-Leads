## 2026-06-06 - Documentation as a User Interface
**Learning:** In repositories where the README acts as the primary interface, treat it as a UI by adding scannable tables, semantic HTML like `<abbr>` for accessibility, and emoji-prefixed contact links to reduce Time-to-Action (TTA).
**Action:** Always include a 'Fast View' link and an inlined preview of key data with direct `mailto:`/`tel:` actions in documentation-only projects.
