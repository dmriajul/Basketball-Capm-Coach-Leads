## 2026-04-11 - [Accessibility & Documentation UX]
**Learning:** Using `<abbr>` tags for industry-specific acronyms (e.g., NBA, NCAA) in documentation significantly improves screen reader clarity and provides helpful tooltips for non-expert users. Additionally, using `<kbd>` tags for keyboard shortcut hints (like Ctrl+F) empowers users to navigate large data sets more efficiently using browser-native tools.
**Action:** Always wrap acronyms in `<abbr>` and use `<kbd>` for interface-related keyboard instructions to enhance accessibility and 'Time-to-Content' for users.

## 2026-04-11 - [Scope Control in Documentation]
**Learning:** Micro-UX improvements should focus on the *interface* of documentation (headers, accessibility tags, layout) rather than introducing new data files which can lead to maintenance overhead and data integrity issues.
**Action:** When acting as a Palette agent, prioritize structural and semantic enhancements over content expansion unless specifically requested.
