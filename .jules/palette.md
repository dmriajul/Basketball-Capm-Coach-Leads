## 2026-05-01 - README as Primary UI
**Learning:** In documentation-centric projects where the README acts as the primary UI, incorporating accessible acronym expansions (<abbr>) and descriptive link titles significantly improves screen reader context and 'Time-to-Action' for users navigating datasets.
**Action:** Always use <abbr> tags for industry-specific acronyms (NBA, NCAA) and provide descriptive 'title' attributes for all external links.
