## 2026-04-21 - Accessible Acronyms and Keyboard Hints in Documentation
**Learning:** In documentation-centric projects where the README acts as the primary UI, using `<abbr>` tags for acronyms and `<kbd>` tags for keyboard shortcuts significantly improves accessibility and provides helpful context for both screen readers and visual users.
**Action:** Always wrap industry-specific acronyms in `<abbr title="...">` and input instructions in `<kbd>` when enhancing README-based dashboards.
