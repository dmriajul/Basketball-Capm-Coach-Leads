## 2026-04-05 - [README Accessibility and Trust]
**Learning:** Using status badges (e.g., Shields.io) for data metrics and `<abbr>` tags for acronyms significantly improves trust and accessibility in documentation-only repositories where the README is the primary UI.
**Action:** Always include status badges for data scale/freshness and wrap industry-specific acronyms in `<abbr>` tags to support screen readers and non-expert users.

## 2026-04-10 - [Entity Interlinking in Data Tables]
**Learning:** Interlinking related entities (e.g., Team Names) within a data preview table significantly reduces "Time-to-Action" for users who need to verify both camp and organizational details without returning to the main spreadsheet.
**Action:** When presenting data tables, identify high-value secondary entities and provide direct links with descriptive `title` attributes to enhance scannability and accessibility.
