## 2026-06-05 - [Documentation as a User Interface]
**Learning:** In repositories where the README.md is the primary entry point, treating it as a functional UI by reducing 'Time-to-Action' (TTA) with inlined previews and direct communication links (mailto/tel) significantly improves utility and accessibility.
**Action:** Use semantic HTML tags like <abbr> and <kbd> in Markdown to enhance screen reader support and provide visual affordance for keyboard shortcuts.
