# 🎨 Palette's UX Journal

## 2026-03-15 - [Contextual Status Badges]
**Learning:** For data-centric repositories, providing immediate context on the dataset size and freshness via status badges at the top of the README improves user trust and reduces initial cognitive load.
**Action:** Always include "Total Leads" and "Last Updated" badges for datasets.

## 2026-03-15 - [Search Visibility]
**Learning:** Users often overlook native browser search (Ctrl+F) when presented with a large data preview table. Explicitly mentioning this with a visual tip improves discoverability.
**Action:** Use GitHub callouts ([!TIP]) with <kbd> tags for keyboard shortcuts to guide users on how to search the data.
