## 2026-07-08 - Semantic HTML in Documentation-Only Repositories
**Learning:** In repositories where the `README.md` serves as the primary user interface, leveraging semantic HTML tags like `<abbr>` for tooltips and `<kbd>` for keyboard shortcut hints significantly enhances accessibility and scannability without requiring external UI frameworks.
**Action:** Always consider the `README.md` as a UI component and apply the same accessibility standards (ARIA, semantic tags, actionable link protocols) as one would in a traditional frontend application.
