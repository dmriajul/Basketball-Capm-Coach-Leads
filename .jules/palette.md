## 2026-04-29 - README as Primary UI
**Learning:** In documentation-centric projects where the README acts as the primary User Interface (UI), incorporating accessible acronym expansions (<abbr>) and descriptive link titles significantly improves screen reader context and 'Time-to-Action' for users navigating datasets.
**Action:** Prioritize horizontal navigation bars, categorical icons for rapid scanning, and semantic HTML enhancements like `<kbd>` and `<abbr>` in all future documentation-only repository improvements.
