## 2026-06-30 - Protocol Link Labels UX
**Learning:** Reviewers and users prefer human-readable labels for links (e.g., "214-747-6287") instead of including the protocol (e.g., "tel:214-747-6287"). This improves scannability and aesthetics in documentation tables.
**Action:** Always format `mailto:` and `tel:` links with clean, protocol-free labels.
