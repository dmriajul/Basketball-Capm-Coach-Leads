## 2026-04-17 - README-as-UI Accessibility
**Learning:** In repositories where the README serves as the primary interface for data discovery, micro-UX improvements like `<kbd>` tags for search shortcuts and `<abbr>` tags for domain-specific acronyms (NBA, NCAA) significantly improve "Time-to-Content" and screen reader accessibility.
**Action:** Always check for industry-standard acronyms in README documentation and wrap them in `<abbr>` tags to provide context without cluttering the main text.
