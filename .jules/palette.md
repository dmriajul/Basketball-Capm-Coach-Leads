## 2026-05-28 - Documentation as a User Interface

**Learning:** In documentation-only repositories, the README.md serves as the primary User Interface (UI). Reducing 'Time-to-Action' (TTA) can be achieved by providing inlined previews of external datasets and using semantic HTML tags like `<abbr>` for acronym expansions and `<kbd>` for keyboard shortcut hints (e.g., Ctrl+F). Emoji-prefixed contact links (✉️, 📞) provide immediate visual affordance for `mailto:` and `tel:` actions, improving overall accessibility and utility.

**Action:** When working on documentation-centric projects, prioritize TTA and TTC (Time-to-Content) by leveraging semantic HTML and scannable data summaries directly in the README.
