## 2026-07-08 - Accessible README Data Presenting
**Learning:** In documentation-only repositories, the README.md is the primary user interface. Using semantic HTML tags like `<abbr>` for tooltips and separate `<kbd>` tags for keyboard shortcuts significantly improves accessibility and user scannability without adding external dependencies. When writing link labels for telephone (`tel:`) and email (`mailto:`) protocols, avoid including the protocol prefix in the visible label text to optimize usability.
**Action:** Always format keyboard shortcut hints clearly as separate `<kbd>` tags (e.g., `<kbd>Cmd</kbd> + <kbd>F</kbd>`), wrap abbreviations in `<abbr>`, keep protocol prefixes out of link labels, and ensure GitHub-native admonitions have blockquotes prefixing every line.
