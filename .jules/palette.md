## 2026-05-26 - Documentation as a User Interface
**Learning:** In documentation-only repositories, the README.md serves as the primary User Interface. Reducing 'Time-to-Action' (TTA) by providing inlined previews of external datasets with emoji-prefixed contact links and semantic `<abbr>` tags significantly improves accessibility and utility.
**Action:** Prioritize scannable previews and direct 'Fast View' links (like Google Sheets pubhtml) over raw file downloads to enhance immediate user value.
