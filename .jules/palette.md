## 2026-05-12 - README as Primary UI
**Learning:** In documentation-centric repositories, the README.md serves as the primary User Interface (UI). Micro-UX improvements like accessible acronyms (<abbr>), keyboard shortcut hints (<kbd>), and direct action links (mailto/tel) significantly reduce "Time-to-Action" (TTA) and improve usability for screen reader users.
**Action:** Prioritize scannable layouts, thematic visual anchors (emojis), and metadata badges to provide immediate context without requiring external navigation.
