# Palette's Journal - Critical UX/Accessibility Learnings

## 2026-03-20 - Adhering to Role Boundaries and Scope
**Learning:** UX improvements must be strictly balanced with role-specific constraints (e.g., Palette vs. Bolt) and file length limits. Over-delivering on infrastructure (like data cleaning scripts) can compromise the intended focus on micro-UX.
**Action:** Prioritize accessibility (e.g., `<abbr>` tags) and small delights (e.g., keyboard shortcuts) while remaining within defined line limits and role scope.
