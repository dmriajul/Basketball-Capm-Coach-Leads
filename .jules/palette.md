## 2026-05-20 - Documentation as a User Interface
**Learning:** In documentation-only repositories, the README.md is the primary UI. Reducing "Time-to-Action" (TTA) by inlining high-value data previews and providing direct outreach links (mailto/tel) significantly improves the user experience.
**Action:** Use semantic HTML tags like `<abbr>` for domain-specific acronyms and `<kbd>` for keyboard shortcuts to enhance accessibility and scannability in data-heavy READMEs.
