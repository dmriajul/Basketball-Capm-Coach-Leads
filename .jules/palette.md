# 🎨 Palette Journal

## 2026-06-11 - Documentation as a User Interface
**Learning:** In documentation-only repositories, the README.md serves as the primary User Interface. Reducing 'Time-to-Action' (TTA) by providing inlined previews of external datasets with emoji-prefixed contact links and semantic `<abbr>` tags significantly improves accessibility and utility.
**Action:** Prioritize scannable tables with direct `mailto:` and `tel:` links and use `<abbr>` for organizational acronyms.

## 2026-06-11 - Visual Cues and Affordance
**Learning:** Prefixing contact links with emojis (e.g., 📧 Email, 📞 Call) provides immediate visual affordance for the expected action, and using `> [!TIP]` with `<kbd>` tags for keyboard shortcuts maximizes clarity and accessibility.
**Action:** Always include emoji prefixes for action links and use standard GitHub admonitions for tips.
