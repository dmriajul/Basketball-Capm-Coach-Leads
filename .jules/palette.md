## 2026-05-04 - [Accessibility]
**Learning:** In documentation-centric projects where the README acts as the primary UI, incorporating accessible acronym expansions (<abbr>) significantly improves screen reader context and 'Time-to-Action' for users navigating datasets.
**Action:** Use <abbr> tags for industry-specific acronyms (e.g., NBA, NCAA) in README tables and lists to provide full names on hover and improve accessibility.
