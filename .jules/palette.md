## 2026-07-08 - Accessible Contacts in Markdown Documentation
**Learning:** Adding semantic HTML elements like `<abbr>` for team codes, wrapping keyboard shortcuts in separate `<kbd>` tags inside native admonitions, and avoiding protocol prefixes inside the link labels significantly improves the document accessibility and clarity for assistive technologies.
**Action:** Always format phone and email links with clear, prefix-less labels while retaining `mailto:` or `tel:` in the `href`, use separate `<kbd>` tags for modifiers, and use `<abbr>` tags for team acronyms when presenting tables.
