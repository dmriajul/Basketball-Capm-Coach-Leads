## 2026-04-05 - [README Accessibility and Trust]
**Learning:** Using status badges (e.g., Shields.io) for data metrics and `<abbr>` tags for acronyms significantly improves trust and accessibility in documentation-only repositories where the README is the primary UI.
**Action:** Always include status badges for data scale/freshness and wrap industry-specific acronyms in `<abbr>` tags to support screen readers and non-expert users.

## 2026-04-13 - [Entity Interlinking in Data Tables]
**Learning:** Linking secondary entities (like 'Team Name') in a data preview table to their official websites significantly reduces 'Time-to-Action' for users verifying data and improves the professional feel of the documentation.
**Action:** When presenting data tables in a README, interlink high-value entities to their official sources with descriptive `title` attributes to enhance both utility and accessibility.
