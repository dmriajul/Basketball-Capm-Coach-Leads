## 2026-04-29 - [README Accessibility & Clarity]
**Learning:** In documentation-centric projects, the README is the primary UI. Typos in titles (like 'Capm') undermine trust, while missing semantic tags (like `<abbr>` for acronyms) create barriers for screen reader users.
**Action:** Always fix title typos immediately and use `<abbr>` tags for all acronyms (e.g., NBA, NCAA) to improve context and 'Time-to-Content' (TTC).
