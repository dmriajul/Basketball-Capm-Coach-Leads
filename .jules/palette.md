# Palette Journal - Basketball Camp Coach Leads

## 2026-05-31 - Documentation as a User Interface
**Learning:** In documentation-only repositories, the README.md is the primary UI. Reducing Time-to-Action (TTA) by providing inlined previews of external datasets with emoji-prefixed contact links and semantic `<abbr>` tags significantly improves accessibility and utility.
**Action:** Prioritize scannable tables with direct `mailto:` and `tel:` links and use `<abbr>` for domain-specific acronyms to enhance screen reader support.
