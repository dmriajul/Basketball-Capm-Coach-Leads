## 2026-06-16 - Scope Control in Documentation-Only Repos
**Learning:** In repos where the README is the primary UI, introducing multiple UX features (tables, badges, and admonitions) simultaneously can be perceived as "over-reaching."
**Action:** Prioritize a single high-impact structural improvement (like a scannable table with semantic tags) to ensure a focused "Palette" contribution and strictly adhere to the 50-line limit.

## 2026-06-16 - Data Consistency as UX
**Learning:** Providing a "UI-optimized" table that contradicts a provided source file (e.g., outdated leads in a CSV) creates functional confusion that outweighs visual or accessibility improvements.
**Action:** Always verify the source data quality before inlining it, and avoid committing low-quality or inconsistent data artifacts to the repository root.
