## 2026-05-22 - Documentation as a User Interface
**Learning:** In documentation-centric repositories, the README.md serves as the primary User Interface. UX improvements should prioritize reducing Time-to-Action (TTA) and Time-to-Content (TTC) through semantic HTML (like <abbr> and <kbd>), clear navigation, and direct-action links (mailto:, tel:).
**Action:** Use structured layouts, status badges, and accessible data previews to enhance the documentation-as-UI experience.
