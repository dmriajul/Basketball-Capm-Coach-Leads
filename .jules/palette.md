## 2026-07-08 - Link Protocol Visual Clarity
**Learning:** Including protocol prefixes (like `mailto:` or `tel:`) in link text labels within README files can clutter the interface and reduce readability, which reviewers flag as poor UX. Formatted text labels (e.g., standard phone/email formatting) with the raw protocol inside the href improve accessibility and look cleaner.
**Action:** Always format visual link text clearly (e.g., '214-469-0822') and place the protocol prefix solely in the URI (e.g., `tel:2144690822`) to ensure optimal user experience and avoid reviewer friction.
