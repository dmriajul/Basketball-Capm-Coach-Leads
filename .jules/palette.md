## 2026-04-05 - [README Accessibility and Trust]
**Learning:** Using status badges (e.g., Shields.io) for data metrics and `<abbr>` tags for acronyms significantly improves trust and accessibility in documentation-only repositories where the README is the primary UI.
**Action:** Always include status badges for data scale/freshness and wrap industry-specific acronyms in `<abbr>` tags to support screen readers and non-expert users.

## 2026-04-06 - [Actionable Data Links and Contextual Clarity]
**Learning:** In a documentation-centric repository, transforming static data previews into actionable links (e.g., linking teams to official websites) and explicitly stating the data scale (e.g., 'Showing 10 of 35') significantly reduces 'Time-to-Action' and improves user transparency.
**Action:** Always look for opportunities to make preview data interactive and provide clear context on the scale of the full dataset.
