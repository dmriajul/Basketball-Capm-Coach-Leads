## 2026-04-14 - Scoping UX vs. Data Integrity
**Learning:** UX improvements must be strictly scoped to interface and accessibility enhancements. Restoring or updating data (like `leads.csv`) can introduce stale or incorrect information, which ultimately degrades UX. "Micro" means focused; a 50-line limit is a crucial guardrail.
**Action:** Prioritize accessibility tags (`<abbr>`) and professional polish (fixing typos) over bulk data restoration in UX tasks.
