## 2026-04-21 - Improving "Time-to-Content" for Spreadsheet Data
**Learning:** For repositories where the primary data lives in external spreadsheets, providing a zero-latency 'Quick Preview' table and a lightweight 'Fast View' link (~9KB pubhtml) in the README significantly reduces the 'Time-to-Content' bottleneck compared to heavy third-party UI initialization.
**Action:** Always include a top-5 leads preview and a direct HTML export link when documenting spreadsheet-based datasets.

## 2026-04-21 - Semantic Accessibility for Basketball Data
**Learning:** Using `<abbr>` tags for sports-specific acronyms (NBA, WNBA, NCAA, DI) and `<kbd>` tags for keyboard shortcut hints (Ctrl+F) provides essential context for screen readers and improves navigability in data-dense documentation.
**Action:** Incorporate acronym expansions and keyboard hints in all documentation-centric landing pages.
