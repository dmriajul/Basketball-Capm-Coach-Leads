## 2026-04-21 - [Documentation-as-UI]
**Learning:** In documentation-only repositories, the `README.md` serves as the primary User Interface. Micro-UX improvements should focus on "Time-to-Content" and "Time-to-Action" by providing zero-latency data previews, accessible acronym expansions (`<abbr>`), and clear keyboard navigation hints (`<kbd>`).
**Action:** Always include a small, high-value data preview and direct "Fast View" links to external data sources to reduce user cognitive load and payload overhead.
