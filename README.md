## 📊 Data Coverage

This resource provides detailed contact information for coaching staff and camp organizers, including:

- **Leads Categories**: NBA, WNBA, NBA G-League, Collegiate (NCAA, JUCO), and Elite Private Camps.
- **Available Data Points**:
  - Basketball Camp Name & Website
  - Team Name & Website
  - Coach/Contact Name
  - Email Address
  - Phone Number (where available)
