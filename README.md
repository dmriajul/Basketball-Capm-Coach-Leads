## 🚀 Quick Start

To begin using these leads, we recommend viewing the database in **Published Web View** for the fastest access.

1.  **Access Data:** Open the [📊 Leads Database](https://docs.google.com/spreadsheets/d/15aaf3T3SSK_JptoitO8avud5TEzp0EEtZERNa9MAR-8/pubhtml "Open spreadsheet in lightweight preview mode").
2.  **Filter/Search:** Use <kbd>Ctrl</kbd> + <kbd>F</kbd> to find specific teams or coaches.
3.  **Export:** If you need to edit, use the "File > Download" option within the spreadsheet.
